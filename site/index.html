3ステップで遊べます

  1. 1

    ログイン

    DiscordとMicrosoftアカウントでログイン。パスワードをランチャーが覚えることはありません。

  2. 2

    サーバーを選ぶ

    所属しているDiscordサーバーのアイコンが、上にタイル状に並びます。押して、遊びたいサーバー名(s1 など)をクリックするとマイリストに追加。

  3. 3

    プレイ

    「プレイ」を押すと、必要なMOD・Java・ローダーを自動で用意して起動。指定サーバーへ自動で接続できます。

初心者に優しい、全部おまかせ

🔄 起動時に自動更新

管理者がパックを更新すると、次の起動で差分だけ自動ダウンロード。古いMODの入れ替えも自動です。

☕ Javaも自動

バージョンごとに違うJavaを、公式のものを自動で用意。自分でインストールする必要はありません。

📌 みんな同じ版で遊べる

管理者がパックのバージョンを固定すると、全員が同じ版に揃います。新しい版が出ても、管理者が切り替えるまで変わりません。

🧩 主要ローダーに対応

Fabric / Quilt / Forge / NeoForge、そしてバニラに対応しています。

📦 いろいろなパックに対応

Modrinth・CurseForge・FTB(Feed The Beast)のモッドパックや、zip / .mrpack も、そのまま使えます。

🕰 あらゆるバージョン

最新版からスナップショット、古いバージョンまで、Minecraftにあるバージョンを管理者が指定できます。

🖥 3つのOSに対応

Windows(exe)、macOS(dmg)、Linux(AppImage / deb)で動作します。

🟢 サーバーの状況が見える

マイリストに、各サーバーのオンライン状況・人数・応答時間を表示。メインのサーバーが落ちているときは、管理者が登録した予備のアドレスへ自動で接続します。

💾 メモリはサーバーごとに

重いMODパックは多め、軽いサーバーは少なめに。割り当てるメモリを、サーバーごとに選べます。

🧾 ログをワンクリックで共有

不具合のときは、ゲームのログやクラッシュレポートをボタン1つで mclo.gs にアップロードして、共有用のURLを作れます。アクセストークンとユーザー名は伏せて送ります。

🔔 アップデートも通知でお知らせ

ランチャーの新しいバージョンは、OSの通知バーで案内。画面のボタンを押すだけで更新できます(インストーラー版 / AppImage)。

🔒 安全面にも配慮

通信はHTTPSのみ。ファイルはハッシュで検証し、初回起動時には配布元を確認するダイアログを表示します。

Discordサーバーの管理者の方へ

Botの導入は不要です。管理サイトにDiscordでログインして、あなたのサーバーに「遊び方」を登録するだけ。メンバーのランチャーに、サーバーのアイコンつきで表示されます。

  • サーバーに s1、s2 のように好きな名前で複数登録
  • バニラ(バージョン指定)/ Modrinth・CurseForge・FTB のモッドパック / .mrpack / zip / manifest から選べる
  • zip は、Minecraftのバージョンとローダーを中身から自動判定
  • パックのバージョンを選んで固定、または最新に自動追従。自動更新のオン/オフも切り替えられる
  • 接続先は予備アドレス(最大3つ)・接続テスト・変更履歴つき
  • 管理者権限がなくても、最初に登録した人(登録者)や、招待リンクで編集者になれる

よくある質問

無料ですか?

はい。ランチャーは無料です。Minecraft Java Editionのアカウントは別途必要です。

Discordでログインが必要なのはなぜ?

あなたが参加しているDiscordサーバーを調べ、そのサーバーに登録されたパックだけを表示するためです。取得するのはユーザー名と所属サーバー一覧(identify / guilds)のみです。

MODは安全ですか?

MODは任意のプログラムを実行できます。信頼できる管理者のサーバーのパックだけ起動してください。初回は配布元を確認するダイアログが出ます。

メモリはどれくらい割り当てればいいですか?

軽いMODパックやバニラなら 2〜4GB、重いMODパックは 6〜8GB が目安です。マイリストの各サーバーで選べます。「既定」のままだと、詳細設定の最大メモリを使います。

パックの自動更新を止められますか?

止めるかどうかは、そのDiscordサーバーの管理者が決めます。管理者がバージョンを固定したサーバーは、全員が同じ版のまま遊べます。

ログを共有しても安全ですか?

ログは外部サービス mclo.gs に送られ、URLを知っている人は誰でも見られます。アクセストークンとパソコンのユーザー名は伏せて送りますが、サーバーのアドレスや導入しているMODの一覧は含まれます。見せてよい相手にだけURLを渡してください。送る前に確認ダイアログが出ます。

Discordの管理者でなくても、サーバーを登録できますか?

まだ誰も登録していないDiscordサーバーは、最初に管理サイトで「登録する」を押した人が登録者になれます。登録者や管理者が発行した招待リンクを使えば、編集者にもなれます。

オフラインモードは使えますか?

オフライン認証のサーバー向けに用意しています。通常のサーバーではMicrosoftアカウントでログインしてください。

公式のランチャーとの関係は?

MojangやMicrosoftとは無関係の非公式ツールです。「Minecraft」はMojang ABの商標です。
