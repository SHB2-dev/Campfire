3ステップで遊べます

  1. 1

    ログイン

    DiscordとMicrosoftアカウントでログイン。パスワードをランチャーが覚えることはありません。

  2. 2

    サーバーを選ぶ

    左に所属しているDiscordサーバーのアイコンが並びます。押して、遊びたいサーバー名(s1 など)をクリックするとマイリストに追加。

  3. 3

    プレイ

    「プレイ」を押すと、必要なMOD・Java・ローダーを自動で用意して起動。指定サーバーへ自動で接続できます。

初心者に優しい、全部おまかせ

🔄 起動時に自動更新

管理者がパックを更新すると、次の起動で差分だけ自動ダウンロード。古いMODの入れ替えも自動です。

☕ Javaも自動

バージョンごとに違うJavaを、公式のものを自動で用意。自分でインストールする必要はありません。

🧩 主要ローダーに対応

Fabric / Quilt / Forge / NeoForge、そしてバニラ。Modrinth・CurseForge・FTB(Feed The Beast)のモッドパックもそのまま使えます。

🕰 あらゆるバージョン

最新版からスナップショット、古いバージョンまで、Minecraftにあるバージョンを管理者が指定できます。

🖥 3つのOSに対応

Windows(exe)、macOS(dmg)、Linux(AppImage / deb)で動作します。

🔒 安全面にも配慮

通信はHTTPSのみ。ファイルはハッシュで検証し、初回起動時には配布元を確認するダイアログを表示します。

Discordサーバーの管理者の方へ

Botの導入は不要です。管理サイトにDiscordでログインして、あなたのサーバーに「遊び方」を登録するだけ。メンバーのランチャーに、サーバーのアイコンつきで表示されます。

  • サーバーに s1、s2 のように好きな名前で複数登録
  • バニラ(バージョン指定)/ Modrinthのモッドパック / .mrpack / manifest から選べる
  • Modrinthパックなら、新しい版を公開するだけでメンバーに自動反映
  • サーバーの管理権限があれば誰でも編集可能

よくある質問

無料ですか?

はい。ランチャーは無料です。Minecraft Java Editionのアカウントは別途必要です。

Discordでログインが必要なのはなぜ?

あなたが参加しているDiscordサーバーを調べ、そのサーバーに登録されたパックだけを表示するためです。取得するのはユーザー名と所属サーバー一覧(identify / guilds)のみです。

MODは安全ですか?

MODは任意のプログラムを実行できます。信頼できる管理者のサーバーのパックだけ起動してください。初回は配布元を確認するダイアログが出ます。

オフラインモードは使えますか?

オフライン認証のサーバー向けに用意しています。通常のサーバーではMicrosoftアカウントでログインしてください。

公式のランチャーとの関係は?

MojangやMicrosoftとは無関係の非公式ツールです。「Minecraft」はMojang ABの商標です。
