プライバシーポリシー

Packhearth(ランチャーと、このサイト・管理サイト)が、どんな情報を扱うかをまとめています。

1. ランチャーと管理サイトで扱う情報

  • Discord ログイン: 「identify」と「guilds」の権限だけを使い、ユーザー名と、参加している Discord サーバーの一覧を取得します。目的は、あなたが参加しているサーバーに登録されたパックだけを表示することです。Discord のアクセストークンは、サーバー側で期限が切れるまで保持し、パスワードは取得しません。
  • Microsoft(Minecraft)ログイン: あなたのパソコンの中でだけ扱います。更新用のトークンは、OS の資格情報の保管庫で暗号化して保存します。Packhearth のサーバーには送りません。
  • 利用状況の集計: 「どの Discord サーバーを、何人が使っているか」を数えるために、ユーザーIDをハッシュ化(元に戻せない形)して保存します。ユーザー名やIDそのものは、この集計には残りません。結果は、数字だけで、開発者が確認します。
  • 管理サイト: ログイン状態を保つための Cookie(セッション)を使います。

Google LLC(Google アナリティクス)このサイトのアクセス状況の集計と、改善(同意した場合のみ)閲覧したページ、ボタンのクリック、ブラウザや端末の情報、おおよその地域、Cookie の識別子など

3. Google アナリティクスについて

このサイト(紹介サイト)では、同意いただいた方に限り、Google アナリティクスでアクセス状況を集計します。同意前は、Google への情報送信も、Cookie の作成もしません。管理サイトとランチャーには、アクセス解析を入れていません。

  • IP アドレスは匿名化して送ります。
  • 同意は、このブラウザにだけ保存されます。いつでも、ページ下部の「アクセス解析の設定」から変更できます。
  • Google による情報の扱いは、Google のポリシーをご覧ください。
  • ブラウザの設定や、Google アナリティクス オプトアウト アドオンでも、収集を止められます。

4. 公開している数字

トップページには、「ダウンロード数」「連携している Discord サーバー数」「登録されたサーバー数」を表示しています。これらは集計した数字だけで、個人や個別のサーバーが分かる情報は含みません。ダウンロード数は GitHub のリリースの集計で、自動更新によるダウンロードも含みます。
